# 3DGS 기반 와이파이 신호 강도 시각화

## 그래픽스 파트 진행 상황 정리

---

## 1. 프로젝트 소개

* 목표

  * 실내 공간에서 측정한 와이파이 신호 강도(RSSI)를 실제 공간 구조와 함께 3차원으로 시각화

* 기존 방식의 한계

  * 2D 히트맵 또는 숫자 목록 형태로 표현
  * 신호 강약은 확인 가능하지만 공간 구조 영향 파악 어려움

* 해결 방법 (통합 시스템 구성)

  * ESP32 장치로 실내 여러 위치에서 RSSI 측정
  * MQTT를 통해 서버로 데이터 전송
  * 서버에서 시간 기준으로 데이터 정리
  * 그래픽스 파트에서 실내 공간 3D 재구성
  * 벽 및 장애물을 고려한 전파 분포 계산
  * 3D 히트맵으로 시각화

* 그래픽스 파트 역할

  * 실내 공간 3D 장면 재구성
  * 신호 분포 계산 및 시각화

* 현재 진행 상태

  * 공간 재구성 완료
  * 전파 계산용 장면 생성 완료

---

# 2. 그래픽스 파트의 전체 흐름

```text
실내 공간 사진 촬영
        ↓
3D Gaussian Splatting 장면 생성
        ↓
전파 계산용 간단한 공간 모델 생성
        ↓
미터 단위 좌표 변환
        ↓
전파 경로 계산
        ↓
신호 분포 생성 (현재 여기까지 완료)
        ↓
3DGS 장면 위 히트맵 표시
```

## 2.1 실내 공간 사진 촬영

* 강의실을 다양한 방향에서 촬영
* 총 205장 사진 사용
* 촬영 목적

  * 공간 구조 확보
  * 카메라 위치 추정

---

## 2.2 3차원 장면 재구성 - PGSR: Planar-based Gaussian Splatting for Efficient and High-Fidelity Surface Reconstruction

* 카메라 위치 계산 후 3DGS 적용

* PGSR 소개

  * PGSR은 기존 3D Gaussian Splatting을 확장한 방법으로, 단순히 공간에 퍼져 있는 가우시안 점들을 사용하는 것이 아니라 이 점들을 실제 물체의 표면에 맞게 점진적으로 정렬시키는 방식
  * 처음에는 가우시안들이 공간에 퍼져 있는 흐릿한 점 구름 형태로 시작하지만, 학습이 진행되면서 각 가우시안이 물체의 표면 방향과 깊이에 맞춰 “표면 위로 눌리듯이” 정렬됨
  * 이 과정에서 가우시안의 위치, 크기, 방향이 계속 조정되면서 서로 겹치고 정렬되어 실제 물체의 외형을 따라가는 얇은 층을 형성
  * 결과적으로 단순한 점 집합이 아니라, 표면을 따라 밀집된 가우시안 집합이 만들어지며, 이를 통해 Mesh에 가까운 구조를 간접적으로 표현 가능

* Mesh 변환

  * PGSR은 학습된 가우시안 분포를 기반으로 표면을 추정하여 Mesh로 변환하는 기능도 제공
  * 일반적으로 TSDF(Truncated Signed Distance Function) 기반 융합이나 Poisson Surface Reconstruction과 같은 방법을 사용하여 가우시안으로부터 연속적인 표면을 복원
  * 변환 결과는 OBJ, PLY로 출력
  * 이 Mesh는 바로 전파 계산이나 추가적인 기하 분석에 활용할 수 있지만, 일부 영역에서는 구멍이나 노이즈가 포함될 수 있어 본 프로젝트의 파이프라인에서는 이후 후처리를 거침

* 정리

  * 실제 강의실과 유사한 3D 장면 생성
  * Mesh 형태의 공간 구조 데이터 확보 (OBJ, PLY 등)
  * 이후 시각화 및 공간 분석의 기반 데이터로 활용 가능

---

## 2.3 전파 계산용 공간 모델 생성

* PGSR에서 생성된 Mesh는 시각적으로는 자연스럽지만, 전파 계산에 바로 사용하기에는 적합하지 않음

  * 표면이 불완전하거나 노이즈가 포함
  * 벽이나 구조물의 경계가 명확하지 않음
* 이를 해결하기 위해 전파 계산에 필요한 핵심 구조(바닥, 벽, 천장 등)만을 반영한 단순화된 공간 모델을 별도로 생성
* 생성 과정

  * 원본 Mesh에서 바닥, 천장, 벽과 같이 큰 평면 구조를 우선적으로 검출
  * 선택된 평면들을 서로 교차시켜 방의 모서리와 경계를 계산
  * 계산된 경계를 기반으로 틈이 없는 닫힌 형태의 방 구조를 생성
  * 이후 전파 계산에 영향을 줄 수 있는 주요 구조(가구 등)만 단순한 형태로 추가하여 전체 공간 모델을 완성

---

## 2.4 전파 경로 및 신호 분포 계산

* 사용 도구: NVIDIA Sionna RT (Mitsuba 3 기반)

  * NVIDIA에서 제공하는 무선 통신 시뮬레이션 라이브러리
  * 실제 공간에서 전파가 어떻게 이동하는지를 물리 기반으로 계산할 수 있는 도구
  * 내부적으로는 Mitsuba 3 렌더링 엔진을 기반으로 한 Ray Tracing 방식을 활용

    * 송신기에서 출발한 전파가 공간 내에서 어떤 경로를 따라 이동하고, 벽이나 물체에 부딪히며 어떻게 반사·감쇠되는지를 정밀하게 추적
  * 단순히 거리 기반으로 신호 세기를 추정하는 것이 아니라, 실제 공간 구조(벽, 바닥, 장애물)와 재질(콘크리트, 목재 등)을 반영한 보다 현실적인 전파 모델을 구성 가능
  * 동일한 거리라도 벽이 있는 경우와 없는 경우, 또는 장애물이 있는 경우에 따라 신호 세기가 어떻게 달라지는지를 분석 가능

*  Sionna RT 사용 시 이점

  * 공간 구조를 반영한 RSSI 분포 계산
  * 장애물(책상, 벽 등)에 의한 신호 감쇠 및 차단 효과 
  * 단순 거리 기반 방식과 달리 벽, 장애물, 재질에 따른 차폐와 반사를 반영할 수 있어, 공간 구조를 고려한 신호 분포를 계산할 수 있음

* 결과

  * 위의 경로들을 종합적으로 계산하여, 공간 내 각 위치에서의 신호 세기를 수치적으로 얻을 수 있음
  * 이후 ESP32에서 측정한 값을 Sionna RT로 계산한 RSSI 분포의 오차를 보정하는 데 사용

* (현재 여기까지 구현된 상태)
