# PNU 강의실 Phase 1.5-A 검증 결과

검증일: 2026-07-11  
실행 환경: `pgsr` Conda 환경, Open3D 0.19.0

## 1. 진단 요약

기존 일반 RANSAC은 점이 많은 수평 구조를 먼저 검출해 수직 후보가 2개에 그쳤다. 누락 벽 점은 일반 추출 잔여점에 남아 있었으므로, 전처리 직후 원본 점구름에서 수직면 가능 점만 고르는 독립 벽 추출 경로를 추가했다.

## 2. 변경 구성

- 법선 분석: 기준값별 수직 후보 PLY, 수평점 PLY, 히스토그램 CSV·JSON
- 벽 추출: 법선 필터, 벽 전용 RANSAC, 평면 법선 재검사, 연결 묶음 병합
- 내보내기: 일반 후보 문서와 벽 후보 문서를 함께 읽는 선택 인자
- 호환성: 기존 후보 JSON의 `source_pass` 누락 시 일반 추출로 해석

## 3. 법선 분석 결과

| 기준 | 통과 점 | 전처리 점 대비 |
|---:|---:|---:|
| 0.25 | 49,920 | 25.68% |
| 0.35 | 61,391 | 31.58% |
| 0.50 | 76,891 | 39.56% |

- 전처리 점: 194,388개
- 유효 법선: 194,388개
- 무효 법선: 0개
- 수평점 기준 0.85 이상: 73,771개(37.95%)
- 추천 기준: **0.25**

위·옆 방향으로 세 기준을 비교한 결과 0.25에서도 외곽 벽 선형 구조가 유지됐다. 0.35와 0.50에서 추가되는 점은 내부 가구와 잡음 비중이 더 커 0.25를 선택했다.

## 4. 벽 추출 구현

벽 추출은 일반 잔여점이 아니라 194,388개의 전처리 원본에서 별도로 시작한다. 0.25 법선 필터를 통과한 점에서 RANSAC을 실행하고, 평면 법선 절댓값 내적 0.25 이하인 평면만 승인했다. 같은 RANSAC 평면의 연결 묶음은 최소 수직 길이를 통과한 경우 합쳤다.

비율만 작은 평면은 제거 후 계속하도록 구현했으며, 실제 실행에서는 작은 비율 종료가 발생하지 않았다.

## 6. 기존 결과 대비

| 항목 | 일반 추출 | 벽 전용 추출 |
|---|---:|---:|
| 수직·벽 후보 | 2개 | 12개 |
| 입력 | 모든 전처리 점 | 법선 필터 통과 점 |
| 외곽 벽 회수 | 부분 벽 2개 | 네 방향 외곽을 따라 다수 후보 생성 |

벽 전용 색상 미리보기에서 이전 잔여점으로 남던 외곽 벽을 후보 색과 사각형으로 회수했다. 다만 같은 벽 방향의 평행 표면이 여러 후보로 나뉘어 있으므로 강의실 외곽이 완성된 것으로 보지는 않는다.

## 7. 실행 명령

```bash
conda run -n pgsr python -m tools.proxy_mesh_editor.main analyze-normals \
  --mesh PGSR/output/pnu_classroom/mesh/tsdf_fusion_post.ply \
  --reference-point-cloud PGSR/output/pnu_classroom/point_cloud/iteration_30000/point_cloud.ply \
  --config tools/proxy_mesh_editor/configs/pnu_classroom.yaml \
  --output outputs/proxy_mesh/pnu_classroom/normal_analysis

conda run -n pgsr python -m tools.proxy_mesh_editor.main extract-walls \
  --mesh PGSR/output/pnu_classroom/mesh/tsdf_fusion_post.ply \
  --reference-point-cloud PGSR/output/pnu_classroom/point_cloud/iteration_30000/point_cloud.ply \
  --config tools/proxy_mesh_editor/configs/pnu_classroom.yaml \
  --output outputs/proxy_mesh/pnu_classroom/wall_extraction
```

## 10. 현재 한계

- 최대 후보 12개에서 종료되어 잔여점에 아직 외곽 벽 조각이 남아 있다.
- 동일 방향의 평행 표면과 두께가 여러 후보로 나뉜다.
- 후보 수가 늘었다는 사실만으로 올바른 방 외곽이 완성됐다고 볼 수 없다.
- 기준값과 장면별 높이 방향 설정에 영향을 받는다.
