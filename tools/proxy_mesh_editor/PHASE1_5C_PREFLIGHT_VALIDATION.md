# Phase 1.5-C 실제 크기 보정 사전 진단 결과

## 결론

현재 Room Envelope의 내부 상하 관계와 닫힌 형상은 정상이다. 장면 위쪽을 `+Z`에 맞추는 변환도 반사가 아닌 순수 회전으로 검증됐다. 다만 두 문 크기는 사진 기반 추정치이고 두 기준 배율이 8.15% 차이나므로, 추천 배율 `1.543624623 m/scene unit`은 현장 실측 전 임시값이다.

이번 단계에서는 실제 미터 단위 OBJ를 만들거나 원본 Room Envelope를 수정하지 않았다.

## 기준 상태

- 로컬 `main`: `497f25ff7f947e5fb8fb741ea600a398d861c09e`
- 원격 `main`: HTTPS 인증 정보를 사용할 수 없어 확인하지 못함
- 입력 형상: 꼭짓점 8개, 삼각형 12개, 경계 모서리 0개, 비다양체 모서리 0개
- 도구 버전: `0.4.0`

```bash
conda run -n pgsr python -m tools.proxy_mesh_editor.main calibration-preflight \

  --output outputs/proxy_mesh/pnu_classroom/calibration_preflight
```

## 위쪽 방향과 MeshLab 판정

- 장면 위쪽: `[0.095501088, -0.991611295, -0.087100992]`
- 바닥 중심에서 천장 중심까지의 위쪽 거리: `1.481499817 scene unit`
- 대응점별 높이: `1.347743194`, `1.373235895`, `1.606063113`, `1.598957065 scene unit`
- 네 높이가 모두 양수이므로 장면 내부의 바닥·천장 관계는 정상이다.
- MeshLab에서 뒤집혀 보였다면 실제 형상 반전보다 MeshLab의 화면 축과 장면 위쪽 축이 다른 것이 원인일 가능성이 높다.
- 바닥 법선과 장면 위쪽의 절댓값 내적은 `0.999477161`, 천장은 `0.997791019`다. 바닥·천장 법선 사이의 작은 각도는 `2.017800812°`이며 자동으로 평행하게 보정하지 않았다.

## 순수 회전 검증

- 회전축: `[-0.995394304, -0.095865426, 0]`
- 회전각: `94.996851043°`
- 행렬식: `0.9999999999999999`
- 직교 오차: `1.110223025e-16`
- 위쪽 정렬 오차: `2.031297822e-16`
- 회전 후 원래 좌표로 돌아오는 왕복 오차: `1.779822905e-15`

행렬식이 `+1`이므로 단일 축 부호 반전이나 거울 반사가 아니다. 회전 전후 꼭짓점 수, 삼각형 수, 면 인덱스, 경계·비다양체 모서리, 부호 있는 부피가 유지됐고 부피 차이는 `0`이다.

## 임시 배율 분석

| 기준 | 개별 배율 (m/scene unit) | 추천 배율 적용 오차 |
|---|---:|---:|
| 양문 전체 폭 | 1.479883208 | +0.086143846 m (+4.3072%) |
| 문 높이 | 1.605636660 | -0.084967219 m (-3.8621%) |

- 추천 계산법: 가중 최소제곱
- 추천 단일 배율: `1.543624623 m/scene unit`
- 개별 배율의 상대 차이: `8.151200332%`
- 판정: 경고. 5% 경고 기준을 넘지만 20% 실패 기준보다는 작다.

축마다 다른 배율은 각도와 전파 경로를 왜곡하므로 지원하지 않는다.

## 좌표 프레임 후보

- 원점 후보: 바닥점 `0`
- 이유: 장면 위쪽으로 투영한 값 `-1.007580072`가 가장 작음
- X축 후보: 바닥 모서리 `2 → 3`
- 위쪽 성분을 제거한 길이: `9.964555630 scene unit`
- 수평 방향: `[-0.701213446, -0.129121663, 0.701161394]`

이는 다음 단계의 설정 초안일 뿐 최종 좌표 프레임은 아니다.

## 생성 파일과 확인 항목

결과 폴더는 `outputs/proxy_mesh/pnu_classroom/calibration_preflight/`다.

- `calibration_preflight.json`: 전체 수치와 판정
- `calibration_preflight_report.md`: 사람이 읽는 진단 보고서
- `scale_analysis.csv`: 계산법별 배율과 기준별 오차
- `room_envelope_up_aligned.obj`, `.ply`: 배율·이동 없이 위쪽 회전만 적용한 형상
- `coordinate_axes.ply`: 원래 위쪽, 목표 `+Z`, 좌표축, 바닥·천장점
- `pnu_classroom_metric_calibration_draft.yaml`: 다음 단계 입력 초안

미리보기에서 네 천장점이 대응 바닥점보다 `+Z`에 있고 면의 앞뒤가 유지되는지 MeshLab의 여러 시점에서 추가 확인해야 한다.

- 이 입력이 확정된 뒤에만 원본과 동일한 단일 배율을 사용하는 실제 크기 변환을 구현한다.
