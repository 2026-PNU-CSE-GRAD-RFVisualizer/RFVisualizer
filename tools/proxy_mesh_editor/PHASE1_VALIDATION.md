# PNU 강의실 Phase 1 기술 검증 결과

검증일: 2026-07-10  
실행 환경: `pgsr` Conda 환경, Open3D 0.19.0

## 결론

PGSR 후처리 메시에서 큰 평면 후보를 검출하고, 색상 미리보기와 후보별 통계를 만든 뒤, 선택한 후보를 구멍 없는 사각형 OBJ로 변환하는 흐름이 실제 강의실 데이터에서 동작했다.

현재 수치 기준 임시 선택안은 바닥 1개, 천장 1개, 서로 다른 방향의 벽 2개다. 다만 색상 PLY를 Blender 또는 MeshLab에서 확인하기 전까지 최종 구조로 확정하지 않는다.

PGSR TSDF 생성 격자는 기본 0.002 장면 단위다. 최초 시험의 평면 거리 허용값 0.05239는 너무 넓어 서로 다른 표면을 합쳤고, 최종값은 약 0.01310으로 줄였다.

## 후보 검출

- 반복 시도: 57회
- 승인 후보: 14개
- 방향별 후보: 수평 12개, 수직 2개
- 후보에 배정된 점: 48,854개
- 잔여 점: 145,534개
- 같은 평면에 있지만 떨어져 있는 책상 상판은 연결 묶음 필터로 분리했다.
- 바닥·천장 후보는 구멍 없는 넓은 사각형을 만드는 목적에 맞춰 떨어진 내부점도 함께 사용했다.

## 아직 필요한 검증

1. `plane_candidates_colored.ply`를 Blender 또는 MeshLab에서 열어 `plane_008`, `plane_010`, `plane_012`, `plane_013`이 실제 바닥·천장·벽에 놓이는지 확인한다.
2. 두 벽은 전체 강의실 외곽을 모두 덮지 않는 부분 벽 후보다. 누락 벽은 다음 편집 단계에서 수동 보완하거나 검출 기준을 장면별로 더 조정해야 한다.
3. 좌표는 아직 장면 단위다. Sionna RT 연결 전 실제 미터 크기와 기준점을 보정해야 한다.
4. 여러 바닥·천장 후보가 존재하므로 현재 YAML 선택은 최종 정답이 아니라 재현 가능한 기술 검증용 임시안이다.
